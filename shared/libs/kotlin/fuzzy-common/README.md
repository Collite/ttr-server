# fuzzy-common

> **forked-from:** the legacy predecessor platform (`shared/libs/kotlin/fuzzy-common/`), forked 2026-06-13.
> Maintained independently since the fork; do not assume parity with the original.

Czech-aware fuzzy match primitives (Jaro-Winkler, n-gram, Damerau-Levenshtein) shared between the fuzzy cascade in Themis and the future Echo service. Pure Kotlin, no Calcite or DB dependencies — safe to embed anywhere.
